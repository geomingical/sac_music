# 花蓮地震微地動音樂化 (sac_music)

將 2024-04-03 花蓮 M7.2 地震當天的微地動訊號與氣象資料，轉化為 3 分鐘的音樂作品。

## 試聽

`output/` 資料夾內有 8 種風格（5 原創 + 3 放鬆模式）的 MP3 與 MIDI 檔案，可直接下載試聽。

## 因子對照表

### 微地動（SAC 波形）→ 旋律與節奏

微地動是音樂的**主角**，控制了你聽到的旋律走向和節奏密度。

| 物理量 | 控制的音樂元素 | 對應方式 |
|--------|--------------|----------|
| **波形包絡線振幅** | 旋律音高 | 振幅小 → 低音（C3 附近）；振幅大 → 高音（Bb4） |
| **波形包絡線振幅** | 旋律力度 | 振幅小 → 輕柔（velocity 30）；振幅大 → 強烈（velocity 120） |
| **STA/LTA 事件偵測** | 鼓組觸發 | 偵測到地震波能量突變時觸發打擊 |
| **事件強度** | 鼓的種類與力度 | 弱事件 → 輕拍；中事件 → 中擊；強事件 → 重擊 |
| **事件密度** | 鼓組節奏疏密 | 安靜時段幾乎無事件；地震時大量事件密集觸發 |

**STA/LTA 觸發器**：Short-Term Average / Long-Term Average，地震學標準的事件偵測演算法。當短期平均能量相對長期平均突然升高（比值 > 5.0），判定為一個地震事件。

### 氣象因子（CSV）→ 背景氛圍

氣象資料是**配角**，提供緩慢變化的情緒底色，每小時更新一次。

| 氣象參數 | 控制的音樂元素 | 對應方式 |
|----------|--------------|----------|
| **氣壓 (StnPres)** | Pad 和弦選擇 | 5 種氣壓區間 → 5 種不同和弦，氣壓高低改變和聲色彩 |
| **風速 (WS)** | Pad 力度 | 風大 → 和弦更響亮；無風 → 幾乎聽不到 |
| **溫度 (Temperature)** | Pad 音域 | 低於 7°C → 和弦降一個八度，聽起來更低沉陰暗 |

### 時間軸 → 敘事結構

24 小時壓縮為 180 秒（3 分鐘），形成三段式故事：

```
時間軸（音樂秒數）
0s ─────────── 55s ──── 60s ────────────── 120s ──────── 180s
│   寧靜前奏    │ 漸入 │     地震爆發        │  餘震消退   │
│               │      │                     │             │
│ 稀疏旋律      │ 鼓漸 │  全力旋律+密集鼓     │ 旋律漸弱    │
│ 輕柔 Pad     │  入  │  正常 Pad           │ Pad 衰減    │
│ 無鼓組        │      │                     │ 淡出        │
│               │      │                     │             │
│ 對應真實時間：  │      │                     │             │
│ 00:00~07:53   │      │ 07:58~15:58         │ 16:00~24:00 │
│ (地震前的平靜)  │      │ (主震+密集餘震)       │ (逐漸平息)   │
```

- **地震發生時刻**：UTC+8 07:58:11 ≈ 音樂第 59.8 秒
- **淡入**：開頭 3 秒
- **淡出**：結尾 5 秒

## 腦波放鬆模式

除了上述 5 種風格外，另有 3 種腦波誘導放鬆模式。這些模式不再採用傳統的音符映射，而是參考專業放鬆音樂（如 Brain.fm、Endel、Brian Eno 生成式音樂）重新設計音軌，並嵌入等時振幅調變（Isochronic AM）技術。

- **設計理念**：放鬆模式使用與原創風格完全不同的 sonification 流程。為了減少聽覺疲勞，旋律密度大幅降低至約每分鐘 2 到 4 個音符，且僅使用五聲調式以避免不諧和音。
- **門檻觸發式旋律**：不同於原創風格持續映射資料，放鬆模式僅在地震能量超過平均值 + 1.5σ 時觸發鋼琴或電鋼琴旋律音符，並設有 5 秒冷卻時間。其餘時間僅有氛圍墊底音（Ambient Pad）持續運行。
- **和聲設計**：Pad 使用 Sus2、Sus4 或 Power Chord 等開闊且穩定的和聲結構，取代傳統大三和弦，營造空靈且不具導向感的空間感。
- **無雙耳節拍**：全面改用等時振幅調變（Isochronic AM），不需耳機，使用喇叭亦能產生誘導效果。
- **多層聲音紋理**：參考 Brain.fm 與 Endel 的設計原則，放鬆模式採用五層聲音架構，確保全程不會出現數位靜音：(1) Sub-bass Drone——持續低頻根音（C1-C2 區域），提供物理包覆感；(2) 濾波粉紅噪聲底層——模擬遠方風聲，以 0.1 Hz LFO 呼吸調變；(3) Pad 和弦——Sus2/Sus4/Power Chord，相鄰和弦重疊 3 秒交叉淡入淡出；(4) 稀疏旋律——門檻觸發的鋼琴音符，附帶 12 秒指數衰減殘響；(5) 等時振幅調變——嵌入整體混音的腦波誘導脈衝。

### 三種模式

| 模式 | 檔名 | BPM | 誘導頻率 | AM 深度 | 旋律音色 | Pad 音色 | Drone 音色 | 技術 |
|------|------|-----|---------|---------|---------|---------|------------|------|
| Alpha 放鬆 | `alpha_relax_hualien` | 72 | 10 Hz（固定） | 22% | Rhodes 電鋼琴 | Warm Pad | Sweep Pad | 等時振幅調變 |
| Theta 冥想 | `theta_meditation_hualien` | 60 | 6 Hz（固定） | 25% | Warm Pad | Space Pad | Sweep Pad | 等時振幅調變 |
| 漸進放鬆 | `progressive_relax_hualien` | 66 | 10→6 Hz（掃頻） | 23% | Rhodes 電鋼琴 | Space Pad | Sweep Pad | 等時振幅調變 |

### 技術原理

- **等時振幅調變 (Isochronic AM)**：對整體音樂混音施加目標腦波頻率的餘弦振幅脈衝。公式為 `envelope = 1 - depth × (0.5 - 0.5 × cos(2π × f × t))`。在 22% 深度下，音量會在 78% 至 100% 之間循環脈動。
- **門檻觸發式旋律**：僅在地震訊號強烈時（>mean+1.5σ）觸發稀疏旋律，創造極簡的環境音樂織體。
- **三重平滑處理**：原始訊號經 Hilbert 包絡、Savitzky-Golay（window=1001）與二次 SG（window=501）處理，地震階段更額外施加長視窗 SG（window=2001），將尖銳的地震瞬變轉化為極其平緩的能量曲線。
- **漸進掃頻**：漸進模式在 180 秒內透過相位累計積分，將調變頻率由 10 Hz 線性掃描至 6 Hz。
- **Sub-bass Drone 軌**：使用 Sweep Pad 音色（MIDI Program 95），演奏 Pad 和弦根音降兩個八度（C1-C2 區域），每 2 小時一個持續音符，相鄰音符重疊 3 秒。力度極低（~20-25），作為「感覺到但不會注意到」的底層。
- **粉紅噪聲底層與殘響模擬**：WAV 混音階段加入 1/f 頻譜粉紅噪聲（200 Hz 低通濾波、0.1 Hz LFO 呼吸調變、音量 3%），並對整體音訊施加 12 秒指數衰減卷積殘響（40% wet），使每個音符的尾巴自然延伸至下一個音符出現。

### 使用注意事項

- ⚠️ **可使用喇叭或耳機聆聽**，均具備誘導效果。
- ⚠️ **請勿於駕駛或操作機械時聆聽** Theta/漸進模式，可能引起嗜睡。
- ⚠️ 有癲癇病史者應避免使用等時調變模式。

所有放鬆模式均無打擊樂器，僅保留旋律與背景氛圍軌，以維持平靜的聽覺體驗。
